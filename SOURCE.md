# Source

A copy of [Online Boutique](https://github.com/GoogleCloudPlatform/microservices-demo) at upstream
commit c7cb6d5. It renders three ways: plain manifests in `kubernetes-manifests/`, Kustomize in
`kustomize/`, and the Helm chart in `helm-chart/`.

Upstream's GitHub workflows were left out, so nothing here deploys to Google Cloud. The code is
under the upstream Apache-2.0 license in `LICENSE`.
